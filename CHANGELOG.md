Phiên bản được đánh theo cấu trúc: MAJOR.MINOR.PATCH
### **MAJOR** — Thay đổi lớn, *breaking changes*
*   Tăng khi có thay đổi làm mất tương thích với phiên bản trước.
*   Ví dụ: thay đổi API, xoá tính năng cũ.
### **MINOR** — Thêm tính năng mới, *không phá vỡ tương thích*
*   Tăng khi thêm chức năng mới hoặc mở rộng API mà vẫn giữ được khả năng tương thích.
*   Code cũ vẫn hoạt động bình thường.
### **PATCH** — Sửa lỗi, tối ưu nhỏ, *hoàn toàn tương thích*
*   Tăng khi sửa bug hoặc cải thiện nhỏ mà không thêm tính năng mới.
